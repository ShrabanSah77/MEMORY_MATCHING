# Memory Matching Game

A modern, high-performance Memory Matching game built using **Kotlin** and **Jetpack Compose**. This app features a clean UI/UX, multiple game modes, and user profile management.

## 📱 Features

- **Interactive Dashboard**: A clean home screen with game mode selection, quick stats, and recent activity tracking.
- **Three Game Modes**:
  - **Classic**: Standard 4x4 grid (8 pairs).
  - **Time Trial**: Focused on speed and accuracy.
  - **Expert**: Challenging 6x6 grid (18 pairs) for memory masters.
- **Game Logic**:
  - Smooth card flipping animations.
  - Matching algorithm with mismatch delays.
  - Move counter to track performance.
  - Win detection with celebratory feedback.
- **User Profile**:
  - Customizable profile name (default: **Shraban Sah**).
  - Editable user details via interactive dialogs.
  - Game settings including Sound Effects and Dark Mode toggles.
- **Statistics**: Track games played, win rates, and best times across different modes.

## 🛠️ Technologies Used

- **Language**: Kotlin 2.0+
- **UI Framework**: Jetpack Compose
- **Design System**: Material 3
- **Navigation**: State-based navigation with `AnimatedContent` and `Crossfade`.
- **Icons**: Material Icons Extended
